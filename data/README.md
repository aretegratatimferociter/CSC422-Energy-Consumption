# Data

## Raw dataset

`raw/PJME_hourly.csv` is the PJM East regional series from version 3 of Kaggle's
[Hourly Energy Consumption](https://www.kaggle.com/datasets/robikscube/hourly-energy-consumption/data)
dataset, published by Rob Mulla (`robikscube`). The Kaggle dataset is licensed CC0 1.0/Public
Domain.

- Downloaded: 2026-09-14
- Kaggle version: 3
- Original filename: `PJME_hourly.csv`
- Columns: `Datetime`, `PJME_MW`
- SHA-256: `4eb2b16d42bf07ec41ab55cb842191594cb69452725a6d3c0991658a628fde84`

The full Kaggle archive contains multiple PJM regions. This project intentionally uses only PJME
so that the geographic definition remains consistent across the modeled time range.

## Processed dataset

`processed/PJME_hourly_clean.csv` is generated by the `energy-preprocess` command. It contains a
continuous hourly index with 145,392 rows from January 1, 2002 through August 3, 2018.

- Four duplicate timestamp rows were combined by averaging their reported demand.
- Thirty absent clock hours were added and imputed from historical values only.
- No invalid timestamps, missing targets, or non-positive target values were present in the source.
- Twenty-seven values outside three interquartile ranges are flagged but retained.
- `is_imputed` identifies generated target values.
- `is_outlier` identifies statistical extremes for review.
- SHA-256: `29e242c8b7cbe491bc47178857a7029e2c3a0d540dd0a57d2a0137a8dc8c1f06`

The exact counts and cleaning policies are stored in `processed/data_quality_report.json`.

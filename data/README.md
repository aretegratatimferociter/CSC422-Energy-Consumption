# Data

## Raw dataset

`raw/PJME_hourly.csv` is the PJM East regional series from version 3 of Kaggle's
[Hourly Energy Consumption](https://www.kaggle.com/datasets/robikscube/hourly-energy-consumption/data)
dataset, published by Rob Mulla (`robikscube`). The Kaggle dataset is licensed CC0 1.0/Public
Domain.

- Downloaded: 2026-09-14
- Kaggle version: 3
- Original filename: `PJME_hourly.csv`
- Columns: `Datetime`, `PJME_MW`
- SHA-256: `4eb2b16d42bf07ec41ab55cb842191594cb69452725a6d3c0991658a628fde84`

The full Kaggle archive contains multiple PJM regions. This project intentionally uses only PJME
so that the geographic definition remains consistent across the modeled time range.

## Weather observations

`raw/weather/` holds hourly surface observations from NOAA NCEI Global Hourly (Integrated Surface
Database), downloaded 2026-10-01 from `https://www.ncei.noaa.gov/data/global-hourly/access/`.
Files are the unmodified yearly station CSVs, gzip-compressed and named
`<airport>_<station id>_<year>.csv.gz`, covering 2002 through 2018.

| Airport | Station ID | Role |
| --- | --- | --- |
| PHL | 72408013739 | Philadelphia |
| EWR | 72502014734 | Newark |
| BWI | 72406093721 | Baltimore |
| DCA | 72405013743 | Washington |
| MDT | 72511514711 (2002–2010), 72399014711 (2005–2018) | Harrisburg |
| ABE | 72517014737 | gap-fill donor only |

NOAA moved Harrisburg International Airport to a new station ID in 2005; both are kept and
overlapping hours are combined.

## Population

`raw/population/` holds unmodified U.S. Census Bureau county population files from
`https://www2.census.gov/programs-surveys/popest/datasets/`, downloaded 2026-10-01:

- `co-est00int-tot.csv`: 2000 Census base (`ESTIMATESBASE2000`) and 2010 Census
  (`CENSUS2010POP`)
- `co-est2015-alldata.csv`: vintage 2015 estimates (`POPESTIMATE2015`)

Each city's population is the sum of the PJME-territory counties it represents, as listed in
`src/energy_forecasting/weather.py`. A snapshot applies from its publication date: 2001-04-01,
2011-04-01, and 2016-03-24.

## Weather features

`processed/weather_features.csv` and `processed/weather_quality_report.json` are generated by
the `energy-weather` command and are not committed.

## Processed dataset

`processed/PJME_hourly_clean.csv` is generated by the `energy-preprocess` command. It contains a
continuous hourly index with 145,392 rows from January 1, 2002 through August 3, 2018.

- Four duplicate timestamp rows were combined by averaging their reported demand.
- Thirty absent clock hours were added and imputed from historical values only.
- No invalid timestamps, missing targets, or non-positive target values were present in the source.
- Twenty-seven values outside three interquartile ranges are flagged but retained.
- `is_imputed` identifies generated target values.
- `is_outlier` identifies statistical extremes for review.
- SHA-256: `29e242c8b7cbe491bc47178857a7029e2c3a0d540dd0a57d2a0137a8dc8c1f06`

The exact counts and cleaning policies are stored in `processed/data_quality_report.json`.
